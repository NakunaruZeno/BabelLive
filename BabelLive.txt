Act as a Principal Frontend & Extension Architect. Build a Chrome Extension (Manifest V3) named "BabelLive" that provides real-time AI live translation and overlays dual-language subtitles on HTML5 videos (similar to ViiTor Translate), with an aesthetic inspired by clean, readable anime subbing.

### 1. Product Overview & Architecture
- Extension Name: BabelLive
- Core Mechanism: Captures tab audio / live transcripts -> Processes via AI translation stream -> Injects a customizable, draggable subtitle overlay directly onto the active video container.
- Tech Stack: HTML5, TailwindCSS / Modern CSS, Vanilla JS / TypeScript, Manifest V3 (background worker, content script, popup).

### 2. UI/UX Specifications

A. Extension Popup (`popup.html` & `popup.js`)
- Design Style: Dark-mode glassmorphic theme (#0f172a slate base, cyber-violet and cyan accents).
- Header:
  - BabelLive logo with a glowing live badge.
  - Master Toggle Switch (Enable/Disable live subbing).
- Language Router:
  - Source Language dropdown (Default: Japanese, English, Chinese, Auto-detect).
  - Target Language dropdown (Default: Vietnamese).
  - Swap direction button.
- Subtitle Styling Controls:
  - Font Size slider (14px - 36px).
  - Subtitle Style Presets:
    * "Anime Standard": Bold yellow font, 2px solid black stroke, subtle drop-shadow.
    * "Cinema Crisp": Pure white bold font, translucent dark box background.
    * "Minimalist": Pure white text with high-contrast outline.
  - Bilingual Toggle: Option to show/hide original source speech above translation.
- Status Indicator: Shows low-latency stream status (e.g., "AI Engine: Connected - Latency ~450ms").

B. Video Overlay (`content.js` & `overlay.css`)
- Injected Container: A responsive, transparent wrapper pinned to the video frame (`position: absolute; bottom: 8%; width: 100%`).
- Subtitle Block:
  - Draggable & resizable container with smooth repositioning.
  - Dual line hierarchy:
    * Top row (Original): Font size 14px, color: #e2e8f0, opacity 0.85, text-shadow.
    * Bottom row (Translated): Font size 22px, bold, high-contrast, stroke outline for maximum readability against complex video backgrounds.
  - Fade-in / fade-out animations for smooth text streaming without flickering.
  - Floating hover mini-bar: Quick controls to pin position, copy subtitle, and resize text on the fly.

### 3. Deliverables Required
1. `manifest.json`: Manifest V3 configuration with appropriate permissions (`activeTab`, `scripting`, `storage`, `tabCapture`).
2. `popup.html` & `popup.css`/Tailwind setup: Complete responsive popup UI.
3. `popup.js`: State management for toggles, language selections, and style presets synced to `chrome.storage.local`.
4. `content.js`: Logic to detect `<video>` elements, inject the overlay DOM, handle drag-and-drop mechanics, and render incoming streaming subtitles cleanly.
5. `overlay.css`: Polished anime-style subtitle typography, text stroke, and drag handles.

Ensure modular, clean code ready to wire up with real-time Speech-to-Text and LLM Translation APIs.
