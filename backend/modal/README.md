# BabelLive — Modal Labs Serverless GPU Backend

Production-grade serverless deployment of **Kotoba-Whisper v2.0** (Japanese ASR) and **Qwen2.5-7B-Instruct (4-bit NF4)** on Nvidia T4/L4 GPUs using [Modal Labs](https://modal.com/).

This completely replaces the Google Colab workflow, eliminating notebook disconnections, manual runtime execution, and slow model downloading.

---

## Key Highlights

- **Zero-Download Cold Start:** Model weights are pre-baked directly into the container image during the build phase (`image.run_function()`). The container boots and initializes VRAM in ~5–8 seconds instead of 3–5 minutes.
- **Auto-Scale to Zero (0 Idle Cost):** The container automatically terminates when idle for 2 minutes (`scaledown_window=120`). You are only charged while listening to a stream.
- **Free Monthly Tier:** Modal provides **$30 in free credits every month** (refreshed monthly). A T4 GPU costs ~$0.14/hour, giving you **~200 hours of free live streaming translation each month**.
- **Permanent HTTPS & WSS URL:** No ngrok tunnels, no temporary links, and no token expiry.

## Quick Setup & Deployment Guide

### Step 1: Install Modal CLI (Local Machine)

Open your terminal (PowerShell, Command Prompt, or VS Code terminal) and install the lightweight Modal client:

```powershell
pip install modal
```

### Step 2: Authenticate Account

Run the setup command:

```powershell
python -m modal setup
```

This will automatically open your default web browser. Log in with your **GitHub** or **Google** account to link your terminal in 5 seconds.

---

### Step 3: Deploy to Modal Cloud

From your project root directory (`BabelLive`), run:

```powershell
modal deploy backend/modal/app.py
```

#### What happens during deployment:
1. Modal remotely builds a Debian Linux container in the cloud with CUDA & PyTorch.
2. Downloads and bakes `kotoba-tech/kotoba-whisper-v2.0` and `Qwen/Qwen2.5-7B-Instruct` into the container layer (done once).
3. Prints your permanent production endpoint in the console:

```text
✓ Created objects.
├── 🔨 Created web => https://<your-workspace>--babellive-backend-babelliveservice-web.modal.run
```

---

### Step 4: Connect to BabelLive Chrome Extension

1. Take the base URL generated by Modal (e.g. `https://your-workspace--babellive-backend-babelliveservice-web.modal.run`).
2. Replace `https://` with `wss://` and append `/ws/live`:
   ```text
   wss://your-workspace--babellive-backend-babelliveservice-web.modal.run/ws/live
   ```
3. Open the **BabelLive Extension Popup** in Chrome.
4. Paste this URL into **WebSocket URL** (or Colab WebSocket URL).
5. Toggle the switch to **ON**.
6. Open any YouTube livestream or video — subtitles will appear automatically with zero local GPU usage!

## Development & Local Testing

If you want to test changes live with interactive log streaming:

```powershell
modal serve backend/modal/app.py
```

`modal serve` creates an ephemeral development URL with hot-reloading. Press `Ctrl + C` when finished.
